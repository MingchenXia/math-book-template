# SGPT layout and colors

Use the layout and color theme of Mingchen Xia's *Singularities in
Global Pluripotential Theory* (SGPT) for books created from this template.
Apply the same settings when adding a chapter, changing the front
matter or revising the PDF.

- Compile with XeLaTeX. Use the SVMono monograph class with
  `envcountsect`, New TX text and mathematics, and the class's
  theorem and proof environments.
- Use the SGPT title, preface and contents arrangement. The class
  supplies the part and chapter headings, margins and recto openings.
  Set part introductions in `partbacktext`, as in the starter book.
- Use red internal links, green citations and magenta URLs. Link both
  the text and page numbers in the contents. The central hyperlink
  settings are in the book preamble.
- Use the supplied `svind.ist` to generate the subject index and put
  the references after it. The workflow supplies the references from
  its single BibLaTeX bibliography.

The SVMono class and MakeIndex style are byte-for-byte copies of the
files in the pinned SGPT source. The starter preamble applies its
layout and colors with the template's bibliography and open-problem
catalogue. [SGPT source](https://github.com/MingchenXia/SGPT/tree/f396263f884ba10921a2a1f2bfdc6cfa1822e543) ·
[Published PDF](https://raw.githubusercontent.com/MingchenXia/mingchenxia.github.io/96883f992a34a312aef08c893e5598a274db60ec/Lectures/SGPT_final.pdf)
