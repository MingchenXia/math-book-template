# Author directions

- Identify the intended reader and the prerequisites that the book assumes.
- State the central mathematical question, the intended scope and the main reading routes. Replace the demonstration compactness material with the new book's mathematics.
- Decide which foundational results the book proves and which it imports. Record the placement of historical discussion and source notes, and any particular attribution or source-retention instructions.
- Record the book's language, notation conventions and any required LaTeX style. The template starts in English.
- Add author feedback that applies specifically to this book. State which chapters or cases it governs.

Set these directions before sustained drafting and keep the chapter dependency map current. Candidate solutions and mathematical revisions follow the repository's independent review and author-approval process. [Book-writing guide](docs/book-writing.md) · [Blueprint](BLUEPRINT.md)
